# Realistic-Lighting

Free realistic lighting setup for Roblox by [@imlaurensdev-ops](https://github.com/imlaurensdev-ops).

## Installation

1. Download the `.rbxm` file.
2. Import the `.rbxm` into Roblox Studio.
3. Delete the existing children inside `Lighting`.
4. Insert the downloaded lighting setup into `Lighting`.

That's it. Enjoy the realistic lighting!
